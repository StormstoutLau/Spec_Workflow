# 外部有效性预注册：多基线单案例设计

> **定位**: 本文档是**预注册（pre-registration）**，不是实验报告。在外部仓被点名并完成测量前，本文档**不产生任何效果声明**。
> **来源**: P-114（裁决 4 = B 档），承 P-109 登记的外部评审项「外部项目对照实验（研究议程）」。
> **上位**: [FWK-ASSERTION](ASSERTION_EVIDENCE_FRAMEWORK.md)（证据分级 E1-E5）——本文档的指标必须可机械重放；阈值类结论按 C 类标注。
> **状态**: `registered / unexecuted`（2026-10-21）。

## 1. 问题与缺口

- M7 39 个样本中 **34 个来自本仓（87.2%）**、1 个 Cpp_Hub 吸收案例、1 个外部评审本仓、3 个未标注 ⇒ 现有证据是**自测**，不能回答「本仓之外是否同样有效」。
- README 已显式标注「方法论自测（无外部对照）」，故不存在过度声称；本文档只补**外部证据的设计**，不修改现有结论。

## 2. 设计类型（预注册冻结）

- **多基线单案例设计**（multiple-baseline single-case across repositories）：3 个外部仓**错开启动**，每仓自身前 / 后测，形成跨仓时间序列对照。
- **为何不用随机双组**：单人开发者、无并行对照团队、任务异质；随机化双组不可行，且会引入模型 / 任务混杂。
- **可主张的因果强度**：时间关联 + 跨仓重复；**不主张**统计显著性或普适因果。
- **外部标准对齐**：ACM SIGSOFT Empirical Standards 的 Case Study / Longitudinal Studies；N-of-1 / 单案例实验设计（SCED）传统。

## 3. 外部仓选择（执行前置）

- 来源 = **G-11b 候选 13 项**（P-104 登记；权威源在学术仓 `INDEX.md`，**执行时须重测**）。
- 硬性排除：`PhD`（个人 / 职业红线）、`论文参考资料`（资料层非项目）。
- 选取规则：① git 仓且含可解析文档；② 本仓**只读**（零写入）；③ 3 仓任务类型不同（避免同质）；④ 错开启动（每仓间隔 ≥1 批）。
- **未点名 ⇒ 不执行**（本预注册保持 `registered / unexecuted`）。

## 4. 指标（机械可算）

| ID | 指标 | 操作定义 | 数据源 | 证据级 |
|----|------|---------|--------|--------|
| **M1** | 文档一致性违规密度 | （断链 + 版本引用不一致 + 过时代码元素引用）/ 千行文档 | 只读脚本（归档于本仓，可重放） | E1 |
| **M2** | 返工次数 | 同一问题在后续批次被再次修正的次数（按批） | 外部仓决策流 / PROGRESS 等价物 | E2 |
| **M3** | 形态 II 复发 | 低语义字段错值（计数 / 版本 / 行号 / 映射 / 引文）处数（按批） | FWK-ASSERTION 分级复核 | E2 |
| **M4** | 轮次数 | 批次从立案到 done 的 review / revise 轮次 | 决策流 | E1 |
| **M5** | 独立评审发现数 | 外部独立评审（若有）发现条数；**无则记 N/A，不记 0** | 评审记录 | E3/E4 |

## 5. 测量时点

- **T0** = 引入前基线（至少 1 批自然产出）；
- **T1** = 第 1 批完成后；
- **T2** = 第 2 批完成后；
- 每仓 ≥3 个时点；3 仓错开；同一指标同一脚本版本。

## 6. 预注册判据（C 类，冻结）

- **支持**：M1 与 M3 的 T2 中位数 ≤ T0 的 **70%**，且在 **≥2/3** 仓成立。
- **不恶化**：任一仓 M1 / M3 增幅 ≤ **20%**。
- **不支持**：未达支持且未恶化——如实登记为负结果。
- **不确定**：<2 仓完成或数据缺失。
- 以上阈值在执行开始后**不得修改**；修改即触发第 10 节的版本作废规则。

## 7. 效度威胁与缓解

| 威胁 | 缓解 |
|------|------|
| 任务异质 | 记录每仓任务类型；跨仓只比方向，不比绝对值 |
| 模型漂移 | 记录执行模型与版本；同仓前后测尽量同模型 |
| 仪器偏差 | 指标脚本归档 + 双跑一致；全程只读 |
| 选择偏差 | 候选仓按 G-11b 规则选取，**不按结果挑** |
| 单人执行 | 外部独立评审（若有）作第二视角；无则如实降级 |
| 霍桑效应 | 只读基线；不可告知外部仓维护者，若不可行则登记 |
