## 决策依据

### ① 分类由「吃狗粮适用性」单轴改为「可动性五轴」

2026-09-29 版用「可 / 轻批 / 不该」单轴，**不足以承载新增的「已裁决·待执行」这一类** ⇒ 重写为**可动性五轴**：有硬期限 / 阻塞性未决项 / **已裁决·待执行** / 触发驱动未激活 / 观察项与跨仓。

### ② 逐项标「可动性」而非「是否开工」

本仓核心目标 = 抑制**形式化审查表演** ⇒ 对**触发未满**的观察项，正确处置是「**等触发**」；**触发未满却主动开全套吃狗粮流程 = 表演**。故下表不判「该不该做」，只判**可动性**（可做 / 等窗口 / 等裁决 / 等触发 / 不需批）。

### ③ 全仓三处「唯一」的裁定

- **唯一「现在可做」** = PT-2 / PT-2E 门面批（已裁决待执行）。
- **唯一真阻塞** = **U-6**（存量豁免面处置口径；同时卡住「开关常开」+ 件②载体迁移 + contract 收口）。
- **唯一有硬期限** = ADR-0006 失效条件③（到期 **2026-11-15**；已复算三次且均不改判，依 P-056 元观察**不重复提前复算**）。
