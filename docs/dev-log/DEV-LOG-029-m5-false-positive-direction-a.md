## 决策依据

### ① 为何选 A 立即实施（而非 B / A+B / C）

A **零风险高收益**（把两次实际处置固化为显性纪律）；B 现做属**过度工程**（收益纯未来性、存量 0、频率约 1 例每 20 天，且兼容成本实测非零）；C 保留每次复现的排查成本。A 与两次事实处置一致。

### ② 为何 B 上调触发阈值

B 触发由「同类复现 ≥1 例（已达 2 例）」**上调为「同类第 3 例 或 用户裁决」**——理由 = A 落地后**规避成本趋零** ⇒ B 的存在理由相应减弱。

### ③ Type-1/2 委派的落点

A 属 **Type-2 单点可逆**（删一句即回退）⇒ 依 P-058 委派**不启动矩阵**（本批五维分析用于**成本收益对比**而非强制矩阵流程）；B 属**阻断路径改动** ⇒ 按 Type-1 待遇留全维度取证。
