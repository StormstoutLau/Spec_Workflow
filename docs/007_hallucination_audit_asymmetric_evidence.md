# Discovery 007: 幻觉点清单自身含幻觉 — LLM 调研产出的不对称证据审计框架

**状态**: RESOLVED (方法论已落地为可执行工具)
**版本**: v1.2 (2026-08-16; 公共承载 = docs/ASSERTION_EVIDENCE_FRAMEWORK.md v1.2, 两者同步维护; 权威源 = 本仓库, 见 ADR-0006)
**模块**: docs/ASSERTION_EVIDENCE_FRAMEWORK.md + scripts/assertion_audit.py (跨模块方法论)
**发现日期**: 2026-08-16
**发现背景**: Phase 7C (v1.7 多变量时序与混频模块) 调研产出经 3 审计 agent 全量独立重查, 发现"排幻觉点"的调研报告自身含 8 处实质错误 — 其中两处 (V8/CI5) 属"把正确事实标成幻觉"型, 对下游 spec 危害大于幻觉本身

## 问题描述

Cpp_Hub 的调研工作流以"幻觉点清单"为核心产出 (Phase 7B 51 项 G/U 编号防幻觉条目, 逐项对照 arch/rugarch/urca 源码, 容差 1e-10~1e-12)。该模式在 v1.6 实施中极为有效。但 Phase 7C 调研 (5 方向并行 agent, 56 个幻觉点) 的产物经独立审计后发现:

**幻觉点清单的作者 (调研 agent) 与幻觉点清单要防的对象 (弱记忆/凭印象断言) 是同一类系统 — 清单本身必然继承同类缺陷。**

具体错误形态分三类 (126 条可验证声明 → 8 处实质错误):

| 形态 | 案例 | 危害等级 |
|------|------|---------|
| **I. 无据断言** (全源零命中仍写出) | NP2: τ_T(k) 的 λ̂−λ̃ 差形式, 4 个独立来源 (双工作稿原文/Stata 手册/Zivot 讲义) 全部是 β̂₀² 形式, 差形式零命中 | 极高 — 直接进入实现会写错 MAIC 滞后选择 |
| **II. 弱记忆填充** (版本号/章节号/数值常量) | zivot_andrews "0.20+" (实为 0.11.0, 0.20 不存在); Lütkepohl "§7.2.2" (实为 §3.6.1); fpp2 "§8.7" (实为 §8.1); ZA MC 临界值 −5.83 当 1% (实为 0.1% 分位值) | 中 — 引用错位, 误导溯源 |
| **III. 把正确事实标成幻觉** (证据全对, 综合推理错) | V8: PS 1998 原式 (12) 分子本来就是 σ_ii⁻¹, 报告却称其为"R 包误记"并改用 DY 2012 的 σ_jj⁻¹ — 两者行归一化后数值不同, 若照抄会写错 DY 溢出指数; CI5: 两处源码引用均正确, "statsmodels 有三套临界值表"的计数结论错 (vecm.py L724-725 的 cvt/cvm 就是 c_sjt/c_sja, 只有一套) | **最高** — 下游实现者会"修正"到错误方向 |

关键观察: **类型 III 无法被"要求给链接"拦截** — 两处源码引用都真实存在且正确, 错误出在综合推理的跳步 (CI5 缺"内嵌表是否就是 c_sjt"这一环的赋值语句证据; V8 缺原式引文)。这是单纯的证据强制规则的盲区。

## 前人方案与缺口

- **传统 code review / 事实核查文献**: 双人评审、清单式核查 (Gawande) — 不适用于 solo developer + LLM 生成的工作流
- **LLM-as-judge 文献** (Zheng et al. 2023 MT-Bench 等): 关注评分一致性, 已知"自我偏好"偏差, 但未按**断言的可验证结构**分类审计策略
- **RAG 引用核查** (如 RARR, Gao et al. 2023): 事后补引文, 但"链接存在"≠"结论可从该页推出" — 引文核验只证明生成者看过该页 (本次 EuropePMC 回退甚至返回身份错误的 PDF: DOI 查询下载到无关 PLOS One 论文, 链接有效但内容错配)
- **形式化验证思想** (本项目 Lean4 路线): 完全排除推理错误, 但成本不可承受于调研阶段
- **缺口**: 无按断言推理结构分级、生成端强制证据与审计端不信任引文**不对称配置**的轻量工作流; 无"机械反证探针优先于 LLM 重查"的工具化实现

## 我的方案

### 1. 断言三级分类 (A/B/C) + 不对称配置

| 级别 | 定义 | 生成端 | 审计端 |
|------|------|--------|--------|
| A 事实类 | 单点外部可验证 (版本/公式/章节/参数语义) | 强制 URL+原文引文(≤3行, 可 grep), 缺则入"假设区"禁入正文 | 机械核验 (脚本) |
| B 推断类 | 综合多源 ("X 与 Y 不同"/"共 N 套"/"无库实现 Z") | 强制编号推理链, 逐步注源, 禁"显然" | 探针+双盲重推导 |
| C 判断类 | 决策/优先级 | rationale+假设声明 | 只查假设是否显式 |

红线: **引文核验只证明"看过该页", 不证明"结论可推出"** — B 类永远需要独立重推导; 审计 agent 不得接触原推理文本 (双盲), 否则锚定效应会把跳步复制一遍。

### 2. B 类三阶段审计 (算子→机械探针→双盲)

按推理算子生成反证探针, 不赌审计者的聪明:

| 算子 | 机械反证探针 | 实测命中 |
|------|-------------|---------|
| 等价/互斥 | 赋值/调用语句 grep (`falsify_on_hit`) | ✅ CI5: `cvm[i,:]=c_sja(...)` 两处命中即证伪"三套表" |
| 存在/不存在 | 候选库枚举+符号零命中 | ✅ NP 无 M 族 (Stata dfgls 不输出, 已实证) |
| 计数 | 枚举全集再数 (非记忆计数) | ✅ demo: 断言 3 套实得 2 |
| 传递/依赖 | 调用图 BFS 找路径 | — |
| 跨库一致 | 同输入两端执行数值 diff | — |

双盲重推导: auditor 只见 {命题, 源证据}, 输出独立推理链; 与原链 difflib 步骤覆盖比对 → **STEP_GAP 检测** (结论一致但重推导步数更多 = 原链跳步藏身处, 不是通过, 进仲裁)。仲裁只裁决分歧步, 不重跑全链。

### 3. 报告即审计输入 (闭环)

调研报告模板 (框架 §7) 内嵌 ```assertions 机读登记块, `audit --input 报告.md` 直接提取重审计 — 报告不再是被审对象, 而是审计工具的输入接口。

## 证据

- **全量审计量化**: 3 审计 agent 独立重查 (文献查 DOI/官方页, 库行为直读源码: statsmodels 0.14.6 / vecm.py / arima.R / midasr 0.9 CRAN tarball / arch v8.0.0 tag): 126 条声明 = 98 确认 + 13 部分确认 + **8 实质错误 (7A+1B)** + 5 无法证实
- **8 错误逐条修正** (PHASE7C_RESEARCH.md v1.1): AR2/V8/CI5/midas_r BFGS/ZA 0.11.0/ZA −5.27644/Lütkepohl §3.6.1/fpp2 §8.1
- **反事实检验**: 7/8 (A 类) 若生成期强制"链接+引文"当场拦截; 唯一 B 类 (CI5) 由探针机械终结 — 分类与工具各自命中设计目标
- **NP2 裁决闭环** (类型 I 的处置实例): `mcp_scholar-mirror.fetch_by_doi` → Semantic Scholar openAccessPdf 绿色副本 → BC wp369 + AU ng_perron00 双工作稿 pypdf 提取 eq.(12) 逐字一致 → 4 源冻结 β̂₀² 形式
- **工具自检**: `assertion_audit.py demo` 离线 4/4 通过 (CI5 证伪/NP 存活/计数证伪/STEP_GAP 检出), commit c0d1d09

## 工具链副发现 (NP2 裁决过程)

1. **EuropePMC 回退 PMID 错配**: DOI 查询管线返回无关论文 (PLOS One 桥梁振动文) — 任何自动下载证据必须先验证 PDF 首页身份
2. Sci-Hub .se/.st 均失败; **Semantic Scholar openAccessPdf 绿色副本路径最有效** (本例 4274 引用的 Econometrica 论文)
3. PDF 文本层排版分拆 ("M AIC") 导致关键词检索漏命中 — 提取须对连字/分拆容错 (改搜公式上下文命中)
4. statsmodels 官方文档自身把 ZA 1992 刊名写错 (Journal of Business & Economic Studies → 实为 Statistics), arch 文档同样误写 — **官方文档不是真值**, 关键断言需双源

## 潜在论文

- 一句话: LLM 生成调研产出的错误呈三类结构 (无据/弱记忆/反向标记), 其中"把正确事实标成幻觉"型对下游危害最大且不可被引用强制拦截, 需按断言推理算子分级的机械反证探针 + 双盲重推导审计
- 目标: arXiv (AI4Research / LLM 评估方向) 或 NeurIPS Datasets & Benchrooms 外的工作流短文; 亦可作为 Research OS 方法论章节
- 优先级: 中 (方法论贡献完整且已工具化, 但需在 ≥2 个后续调研周期收集量化数据: 拦截率/误报率/成本对比, 才可成文)
