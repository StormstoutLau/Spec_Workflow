## 2. 核心发现

### 2.1 启动触发裁决（C 类）

【C】**P-009 正式启动，触发性质 = 用户指令**。PROGRESS 优先级裁决（2026-08-20）将 P-009 定为「触发驱动（优先级 5，不排队）」——外部触发（自动化需求出现）时启动。2026-08-26 用户指令「继续处理 P-009」即触发裁决的显式行使（单人仓：用户即触发条件判据）。**边界澄清**（防语义漂移）：本启动与 LANGGRAPH §6 触发条件 (a)/(b)/(c)（状态管理瓶颈 / 跨会话恢复高频 / S1 周跑批）正交——(a)/(b)/(c) 是「方案 B 运行后是否值得升级 LangGraph」的观察条件，不是 P-009 的启动条件；启动后 (a)/(b)/(c) 随 runner 落地进入登记复查（DESIGN §8）。

【C】**执行批次 = 设计批先行**（用户裁决 2026-08-26）：本轮完成 Step 1-4（RESEARCH + DESIGN，spec 文档落本仓 `spec/spec-runner/`）；实施批（新仓库 `F:\Spec_Runner` 代码 + IMPLEMENTATION + CHECKLIST）下轮触发。理由：① 异构审查臂与 dsh H2 实测被端点不可达阻塞（§2.2），骨架设计不受阻塞 ② runner 为新领域代码（500-1000 LOC），设计先行保证实施批一次到位 ③ 与 P-016 两件套先例同构（小流程裁剪依据 D3 登记）。

### 2.2 端点现状复核（A 类，E1 实测）

【A】三机 LM Studio 端点 2026-08-26 复核仍全部不可达（与 P-010 落地时点 2026-08-23 实测一致，连续两次独立探测同结论）：`curl.exe -s -m 8 http://<host>:1234/v1/models` 三端点均连接失败（curl exit 7 = connection refused，主控站 192.168.1.10 / 工作站 A 192.168.1.11 / 工作站 B 192.168.1.15）——LG-H3 维持未解除。**含义**：① runner 的异构审查臂（LM Studio 端点作模型池）无法实测接入 ② dsh H2 实测（工作站 A 装 SDK + `DEEPSEEK_BASE_URL` 指 LM Studio 端点跑 minimal.py）双端阻塞（工作站操作 + 端点不可达）③ 两者均不阻塞骨架设计——adapter 开放结构（§2.3）与端点配置化 + 就绪门控（承 P-010 方案 Z 模式：不可达即 exit 1 不调后续）是设计层的解法。【来源：本机 curl 实测 2026-08-26，可重放命令如上】

### 2.3 选型开放结构裁决（C 类）

【C】**agent 执行层选型按开放结构进入设计**（用户裁决 2026-08-26）：裸 API 调用为默认实现路径 + adapter 层隔离 + dsh SDK 列为实测后升级候选（dsh H2 就绪时仅换 adapter 不动核心）。依据：① 选型的实质输入（dsh H2 实测）被阻塞，等实测再设计将使 P-009 整体推迟 ② 两分支对设计的影响可隔离在 adapter 单点（LLM 调用 + 工具注册的封装界面），事件流/gate/git 持久化等核心与选型无关 ③ **L7 信任层不受选型影响**——log writer 是 runner 自身的固定组件（取证锚最小且固定），dsh SDK 路线下事件流写入器同样不可替换（§9.4 不吸收清单：插件化 log writer 否决）。

### 2.4 LG H2 设计级 LOC 拆解（B 类，推断）

主体调研的 ~500-1000 LOC 估算（LANGGRAPH §5 方案 B 表 + §9.5 落地约束）在设计级按模块拆解验证，对照本仓三脚本先例（dc_validator 422 行 / m7_stats 845 行 / repo_stats 1276 行——均为零依赖 Python + selftest 同构形态）：拆解表见附录 B basis，七模块（事件流写入器 / gate 执行器 / HTTP 调用层 / adapter 接口 / CLI 入口 / git 持久化 / selftest）核心 ~400-600 行 + selftest ~150-250 行 = **~550-850 行，落入 500-1000 区间**——LG-H2 设计级吻合（实施级 PoC 待骨架落地实测收口）。

## 3. 综合分析

1. **启动合法**：触发条件经用户显式行使成立，启动性质与 LangGraph 升级条件正交登记（防后续语义混淆）[置信度: ★★★★★]
2. **设计批不受阻**：端点不可达阻塞的是实测接入面（异构审查臂 + dsh H2），骨架设计面（事件流/gate/git/CLI/adapter 界面）零依赖外部环境 [置信度: ★★★★★]
3. **LOC 估算设计级吻合**：模块拆解 ~550-850 落入 500-1000 区间，实施批 LOC 预算可按模块下达 [置信度: ★★★★☆（设计级拆解，实施级待 PoC）]
4. **选型风险前置消解**：开放结构把选型从「设计前置条件」降为「adapter 单点替换」，dsh breaking changes 风险（developer preview）被隔离在候选路径 [置信度: ★★★★☆]
