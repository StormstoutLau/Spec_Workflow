# 学术推理写作工作流 S3 运行卡（自足形态）

> **用途**: 把 **S3 推理工作流层**（分步走第三步：S1 契约层 → S2 清理层 → **S3 运行**）的**运行口径**固化为**可直接消费的自足运行卡**——回答「写论文的每一步（调研→缺口→设想→模型→数据→初结果→草稿→模拟评审→反馈迭代）按什么规矩跑、什么算过、卡住怎么办、改前步怎么留痕」。
> **定位**: **运行态辅助**（怎么跑、怎么算过），**不取代**规范本体（什么算合规）。与 [ACADEMIC_FILE_SPEC.md](ACADEMIC_FILE_SPEC.md) 的分工 = 规范回答**静态合规**，本卡回答**动态运行**。
> **上级**: [RESEARCH.md](RESEARCH.md) §17.19（S3 启动记录）。运行口径**全部由既有裁定承接**（C-8 回溯 / C-9 收敛 / 规范 §7 纪律 / 既有执行卡），**本卡不新立规则**。
> **自足化边界（三条）**: ① 只内嵌**判据与红线**，**不新立结论性主张**；② 凡外部依据以规范本体与 RESEARCH 的 A/B/C/H 编号为权威，**本卡不新增编号断言**；③ 两处若不一致，**以规范本体与 RESEARCH 为准**。
> **红线（优先于本文全文）**: 隐私隔离高于整洁、高于规范 ⇒ 共享层 `data_policy.md` 为**首件交付**；**禁止删除任何文件**；**禁止 push 与改写历史**。

---

## 0. 三条不变量（地基）

| # | 不变量 | 含义 |
|---|--------|------|
| I | **一份真值** | 同一事实只在一个地方"是权威"，其余位置只能是**指针或派生物** |
| II | **名 = 身份，版本 = 元数据** | 文件名说"这是什么"，不说"这是第几版" |
| III | **声明 = 机械重数** | 文档里任何数字都须能被程序当场重算 |

## 1. 运行口径（四组）

### 1.1 六轴对齐（每个写作动作的静态合规动作）

| 轴 | 运行中的动作 |
|----|-------------|
| **一 · 对应** | 新结果单元（表 / 图 / 关键数字）先落 `RESULT_MAP.md` 行（论文单元 / 生成程序 / 输入数据 / 输出产物四列齐） |
| **二 · 追溯** | 对应表指针闭合（路径存在）；关键数字禁手填，走宏文件或 `% src:` 锚注 |
| **三 · 版本** | 版本只进**目录 / 标签**，不进文件名（存量豁免，新动作合规） |
| **四 · 血缘** | 新版本 → `LINEAGE.md` 加边（只允许 `derived_from` / `supersedes` / `points_to` 三类） |
| **五 · 日志** | `RESEARCH_LOG.md` 追加条目（ISO 日期 + 动作 / 读数 / 决策 / 未决四字段） |
| **六 · spec 纪律** | 规范 §7 六条——决策记录（7.1）/ 断言分级（7.2）/ 声明=重数（7.3）/ 异基座独立审查（7.4）/ 懒加载 gate（7.5）/ 同名必须同义（7.6） |

### 1.2 回溯口径（C-8：后步证伪前步时）

后步没达到预期需要调整前步（模拟评审要求多步返修 / 数据获取困难重开调研 / 结果不理想重做缺口分析）时，三条固定动作：

1. **非时序回跳到因果源**——跳到**冲突源**那一步，不是「退一步」逐级往回（同 CSP backjumping 语义）；
2. **最小回改集**——只改被影响的前步，不做整链重跑；影响集先在日志「未决」字段显式声明；
3. **旧值留痕**——被改的旧值**不删**，append-only 登记改动前后 + 理由（重大者进 `docs/decisions/`）。

### 1.3 收敛口径（C-9：轮次与进展）

1. **轮次上限**——返修 / 迭代的轮次上限**显式声明**（本卡不设具体数：期刊流程经验值不可直接外推，本地未实测）；
2. **进展判据**——每轮须报「相比上轮改变了什么」；**无进展轮不得无限重试**，超限即触发 C-8 回跳或 kill criteria（规范 §4.5）。

### 1.4 触发口径（懒加载 gate，规范 §7.5）

规范 / 工具只在**触发条件成立**时落地，不预先建成。本卡运行**不预设对象、不预造成文**：下一次真实写作动作即首轮（见 §3）。

---

## 2. 留痕载体（全部为既有件，不新建）

| 事件 | 载体 | 形态 |
|------|------|------|
| 重大变更（改方向 / 改数据口径 / 改核心定义） | `docs/decisions/` | 一件一档、命名唯一、写**采纳与否决两条路径** |
| 每轮动作与读数 | `RESEARCH_LOG.md` | append-only；ISO 日期 + 四字段（**未决不得留空**） |
| 结果单元变化 | `RESULT_MAP.md` | 行更新（四列） |
| 版本继承 / 指向 | `LINEAGE.md` | 三类边字面量 |
| 状态提醒（下一步） | `RESEARCH_LOG.md`「未决」字段 | 每步改动显式写出下一步待办（B2 状态提醒同构） |

---

## 3. 首轮定义（决策 2·B 事件触发）

- **不预设对象**：下一个**真实写作动作**（任一仓的任一环节——新一轮调研 / 一次返修 / 一次数据更新 / 一次评审回应）即**首轮**；
- **首轮最低留痕**：≥1 条 `RESEARCH_LOG.md` 条目（四字段齐）+（若属重大变更）≥1 条 `docs/decisions/` 记录；
- **Type-2 可改**：首轮口径可逆；首轮暴露的缺口即改本卡（缺口 → 规范增补）。

---

## 4. 通过门（每轮运行）

| # | 门 | 判据 |
|---|----|------|
| 1 | **对应门** | 本轮涉及的论文可见单元在 `RESULT_MAP.md` 有行，且指针闭合（未命中数 = 0） |
| 2 | **重数门** | 本轮写进任何文档的计数 / 数字可当场重算（规范 §7.3） |
| 3 | **日志门** | `RESEARCH_LOG.md` 新条目四字段齐、「未决」非空 |
| 4 | **留痕门** | 回溯 / 改值事件有旧值留痕；（重大者）决策记录在案 |

**纪律**: 命令没跑就如实写「未执行」；**不得以「未执行」冒充「通过」**。

---

## 5. 红线（优先于全文，触线即停并在日志标注）

| # | 红线 |
|---|------|
| R1 | **隐私隔离 > 整洁 > 规范**：`data_policy.md` 红线清单定稿前**一切只读**；不触碰红线段 |
| R2 | **禁止删除任何文件**（G1）：未裁决项（归档快照 / 双源 / 文献 PDF）**先登记、后裁决、再动作** |
| R3 | **禁止 push 与改写历史**（G2）；允许**本地原子提交**（该仓有 git 时） |
| R4 | **不得以「未执行」冒充「通过」** |
| R5 | **作用域纪律**：报「未提交 / 未清理」类读数须跑**全局命令**并声明作用域；范围限定读数不等于全局读数 |

- **启动记录** = [RESEARCH.md](RESEARCH.md) §17.19（P-085）：**决策 1·A 首用驱动**（运行态以既有纪律承接——六轴 + §7 + C-8 / C-9；**不建引擎**）+ **决策 2·B 事件触发**（不预设对象）。
