## 2. 逐轴原子动作（S2，逐仓执行；每行独立可回滚）

> **判据口径**: `$proj` = 单仓根（如 `"$wp\LGMM\LGMM 8.0"`）。**每完成一行落一次读数，不堆批**（A-92 strangler-fig：可回滚优于 cutover）。

### 2.1 轴一 · 论文 ↔ 数据 ↔ 程序 严格对应

| # | 动作 | 可机械检出判据 | 通过门 |
|---|------|---------------|--------|
| 2.1.1 | 建 **`RESULT_MAP.md`** | `Test-Path "$proj\RESULT_MAP.md"`；四列表头 = 论文单元 / 生成程序 / 输入数据 / 输出产物 | 四列齐；行数 ≥ 论文侧被引用单元数 |
| 2.1.2 | 论文单元 ↔ 表行 **双向对账** | `(Select-String -Path "$proj\paper\*.tex" -Pattern '\\input\{(tables\|figures)/').Matches.Count` 与 `((Select-String -Path "$proj\RESULT_MAP.md" -Pattern '^\|').Count - 2)` | 表侧 ≥ 论文侧；**论文侧有而表侧无 = 悬挂，禁止** |
| 2.1.3 | 主稿**禁内联表格/绘图** | `(Select-String -Path "$proj\paper\document.tex" -Pattern '\\begin\{tabular\}').Count` | 读数 = **0** |
| 2.1.4 | **未绑定数字清单** | `$s=Select-String -Path "$proj\paper\*.tex" -Pattern '(?<!\\)\d{3,}'; ($s \| Where-Object { $_.Line -notmatch '%\s*src:' }).Count` | 逐条处置（绑定宏 / 落入 §2.1.1 / 白名单），**未处置数 = 0** |
| 2.1.5 | **数值探针**（抽样 ≥5 行） | 抽样行重跑生成程序，输出与论文数字逐位比对 | 三列表落档（论文值 / 重跑值 / 判定）；**不一致项逐条登记** |
| 2.1.6 | 环境声明 | 依赖清单存在且非空（`requirements.txt` / `environment.yml` / `renv.lock` 之一）+ `MANIFEST.md` 有"环境"节 | 两者皆真 |

### 2.2 轴二 · 追溯

### 2.3 轴三 · 版本

| # | 动作 | 可机械检出判据 | 通过门 |

## 5. 红线与禁令（**优先于本卡全部条目**）

1. **隐私优先**: `data_policy.md` 定稿前，一切动作**只读**；绝不触碰红线清单内容。
2. **未裁决不动**: H13 / H14 / H15 与任何"看起来是垃圾"的未决项，**先登记、后裁决、再动作**；**禁止删除**。
3. **不改产出方仓**: 本卡执行不得修改 `f:\Spec_Workflow` 任何文件。
4. **不推历史**: 学术仓的 push/强推属该仓自治，本卡不授权改写历史。
5. **不合并动作**: 每行原子动作**独立成一次可回滚的提交**（A-92）。
6. **不表演**: 判据读数必须来自真跑；**"未执行"必须写"未执行"**——本卡的目的是暴露缺口，不是产出好看的报告。

## 6. 与既有机制的关系

- **与 PILOT_TASK_CARD.md**: 该卡 = 单仓 pilot（`LGMM 8.0`），本卡 = 全仓推进。**pilot 结果先于本卡全量执行**（C-22：不跳过 H12/H13 门禁）。

- **与本仓校验器**: 本卡是**执行态**辅助（怎么按序做、怎么算过），不取代产出方的**产物态**校验器；两者层级分离（A-82）。
- **懒加载**: 本卡 zero 工具 / zero 依赖；若实测证明某轴不适用，**删除该轴并登记理由**，不得留"永远待办"。
