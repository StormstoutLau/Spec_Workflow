# 学术文件规范——论文仓工程规范（P-040 落地 · 规范本体）

> **用途**: 把 P-040 既有调研的裁定固化为**可被单仓直接消费的规范本体**——论文仓（`D:\Article\Working paper\`）中**论文 / 数据 / 程序**三者的严格对应，以及其上的追溯、版本、血缘、研究日志与 spec 式学术纪律。
> **定位**: 本文件 = **规范**（reference / what 层；Diátaxis 禁混模式，A-82）。**执行清单另立**：[PILOT_TASK_CARD.md](PILOT_TASK_CARD.md)（单仓 pilot）与 [ACADEMIC_REPO_TASK_CARD.md](ACADEMIC_REPO_TASK_CARD.md)（全仓推进，交付学术仓 agent）。规范与执行卡**不得互抄**：规范回答"什么算合规"，执行卡回答"今天先做哪一行"。
> **上级调研**: [RESEARCH.md](RESEARCH.md) §15–§17（A-74~A-92 / B20~B26 / C-15~C-23 / H12~H16）。
> **证据纪律**: 本文件**不新增未经核验的外部断言**。所有社区依据一律按既有断言编号交叉引用（见 §8 映射表）；本文件新增内容仅为**规范条目**（约定），**不进入** RESEARCH 的 A/B/C/H 断言计数。
> **红线（优先于本规范全文）**: 隐私隔离高于整洁、高于规范（C-19）⇒ 共享层 `data_policy.md` 为**首件交付**；H14/H15 裁决前**不得删除任何文件**。

## 0. 三条不变量（全文的地基）

| # | 不变量 | 含义 | 本仓同源 |
|---|--------|------|---------|
| I | **一份真值** | 同一事实只在一个地方"是权威"，其余位置只能是**指针或派生物** | I-1 |
| II | **名 = 身份，版本 = 元数据** | 文件名承载"这是什么"，不承载"这是第几版" | I-3 / A-79 |
| III | **声明 = 机械重数** | 文档里写出的任何计数/数字，必须能由程序当场重算出来 | 本仓 R7 纪律 |

> **判据口径**: 本规范全部条目以「**可机械检出**」为合格线（C-16）。凡不能落到一条真命令上的要求，不进本规范正文，只进 §9 未决区。

## 2. 轴一 · 论文 ↔ 数据 ↔ 程序 严格对应

> **现状病灶**（§15 实测）: 论文数字与代码输出之间**无成文对应**；`SABR-v1` 560 行 > `SABR-v2` 288 行——版本入名掩盖了"哪份是当前真值"；`fix_*.py` / `debug*.py` 散落（34 个）说明"生成路径"从未被写成制品。

### 2.1 结果对应表（`RESULT_MAP.md`）——本规范的核心新增

**约定**: 每仓根一份 `RESULT_MAP.md`。**唯一键 = 论文可见单元**（表 / 图 / 正文关键数字），每行绑定三列：

| 列 | 含义 | 必填 |
|----|------|:----:|
| **论文单元** | `paper/` 中的可指认位置（`\input{tables/tab_x.tex}` 或 `\label{fig:x}` 或节号+数字指纹） | ✔ |
| **生成程序** | 仓库内脚本路径 + **入口命令**（含参数） | ✔ |
| **输入数据** | 数据文件路径（+ 版本标签或 hash） | ✔ |
| **输出产物** | 被论文引用的文件路径（+ hash） | ✔ |

**机械判据**:
```powershell
$root = "D:\Article\Working paper\<PROJECT>\<VERSION_DIR>"
# ① 存在性
Test-Path "$root\RESULT_MAP.md"
# ② 论文侧被引用单元数 vs 对应表行数（行数 = 数据行，不含表头/分隔行）
(Select-String -Path "$root\paper\*.tex" -Pattern '\\input\{(tables|figures)/').Matches.Count
((Select-String -Path "$root\RESULT_MAP.md" -Pattern '^\|').Count - 2)
```
**通过门**: ① 为 `True`；② 两侧读数相等（表侧 ≥ 论文侧；论文侧出现而表侧无行 = 悬挂，禁止）。

### 2.2 表格与图一律外置，禁内联

**约定**: 主稿（`document.tex` / `main.tex`）**不含** `tabular` 环境与内联绘图代码；全部经 `\input{tables/...}` / `\includegraphics{figures/...}` 引入。

**机械判据**:
```powershell
(Select-String -Path "$root\paper\document.tex" -Pattern '\\begin\{tabular\}').Count   # 期望 0
(Select-String -Path "$root\paper\document.tex" -Pattern '\\input\{tables/').Count     # 期望 >= 1
```
**通过门**: 前项 = 0。

### 2.3 关键数字必须由程序写出（禁手填）

**约定**: 正文中"结果类"数字（系数、p 值、样本量、显著性、区间）**只能**经生成物引入——或外置为表格，或以 `\input{}` 引入的宏文件承载。手填数字一律视为**未绑定**。

**机械判据**（弱形态，可先落地）: 检查不存在"手写三位以上数字且同处无 `% src:` 锚注"的行；`% src:` 锚注格式 = `% src: <脚本路径> -> <产物路径>`。
```powershell
$suspect = Select-String -Path "$root\paper\*.tex" -Pattern '(?<!\\)\d{3,}'
$unbound = $suspect | Where-Object { $_.Line -notmatch '%\s*src:' }
$unbound.Count
```
**通过门**: 落档时须给出 `$unbound.Count` 的真实读数并**逐条处置**（绑定到宏文件 / 落入 RESULT_MAP / 标注为"陈述性非结果数字"白名单）。**未处置者不得声称合规**（禁止以"看起来很合理"结案）。

### 2.4 数值探针：论文数字 ↔ 程序输出逐一对账

**约定**: 迁移轮必须至少跑一次**数值探针**——对 `RESULT_MAP.md` 中抽样行，**独立重跑程序**并把输出与论文中对应数字逐位比对。

**依据**: P-040 既有实证——"论文横截面 GMM 因子溢价 ≠ 代码收益加权平均"即此类断点（RESEARCH §1 A-2）。

**通过门**: 抽样行给出**三列**（论文值 / 重跑值 / 判定），不一致项**逐条登记**为缺陷；**不得只报一致率而不列不一致项**。

### 2.5 环境指定（可复现的最小条件）

**约定**: 每仓声明运行环境（语言/版本/关键依赖），落在 `MANIFEST.md` 或 `CONVENTIONS.md` 的"环境"节；**声明必须可核对**，不得写模糊表述。

**依据**: A-74（Research Compendium：环境指定为约定结构之一）。

**机械判据**: 存在依赖清单文件（`requirements.txt` / `environment.yml` / `renv.lock` / `Cargo.toml` 之一，按实际栈）且非空；`MANIFEST.md` 中"环境"节存在。

## 3. 轴二 · 追溯

### 3.1 追溯链单向闭合（无悬挂）

**约定**: 追溯方向恒为 **论文单元 → 产物 → 程序 → 数据 → 原始来源**，反向只允许"引用"，不允许"复制内容"（C-20：层间唯一连接是**引用键**）。

**机械判据**: `RESULT_MAP.md` 每一行的"生成程序"列所指路径 `Test-Path` 为真、"输入数据"列所指路径为真。
```powershell
# 对 RESULT_MAP 的路径列逐行 Test-Path（由执行者写成一次性循环）
# 未命中数 = 0 才通过
```
**通过门**: 未命中数 = **0**。不得以"路径大致能猜出来"结案。

### 3.2 数据快照的 hash 清单

**约定**: 仓内**数据**（非第三方公共数据、非红线数据）配 `MANIFEST.sha256`（文件名 + SHA256 两列），供第三方独立核查。

**依据**: A-74 / A-75（compendium 与 RO-Crate 的可核查性内核）。

**机械判据**:
```powershell
Get-FileHash "$root\data\<file>" -Algorithm SHA256
# 与 MANIFEST.sha256 中该行逐字符比对
```
**通过门**: 清单覆盖的数据文件数 = 实际存在的数据文件数；比对不一致项 = 0。

### 3.3 引用接地（文献）

**约定**: 文献引用只经 `.bib` 键（`\cite{key}`）；**仓内不放文献 PDF 的 VoR**（多数出版商不允许自存档，A-86），如需保留按"参考层 + 版本类型标注"处理（C-20）。
**机械判据**: `\cite{}` 中出现的键集合与 `.bib` 条目键集合的**差集 = 0**（脚本一次性抽取比对）。
**通过门**: 差集 = 0；`references.bib` 存在。

## 4. 轴三 · 版本

### 4.1 命名：ISO 8601 或标签范式，禁状态词入名

**约定**: 源文件名（尤其 `.tex` / `.py`）**禁止**状态词入名与空格（`final` / `corrected` / `reviewed` / `rigorous` / `complete` / `new` / `old` / `_vN` 数字版号）。
**依据**: A-79（"一旦 final 进了名字，就没有词留给下一个版本"）。
**机械判据**:
```powershell
Get-ChildItem $root -Recurse -File -Include *.tex,*.py |
  Where-Object { $_.Name -match '(?i)_(final|corrected|reviewed|rigorous|complete|new|old)' }
# 输出必须为空
Get-ChildItem $root -Recurse -File -Include *.tex |
  Where-Object { $_.Name -match '\s' }    # 空格入名：输出必须为空
```
**通过门**: 两段输出均为空（**排除第三方子仓目录**，见 §9 偏离登记）。

### 4.2 版本目录归一（≥5 种 → 2 种）

**约定**: 版本只允许两种形态承载——**(a) ISO 日期目录**（`2026-09-14`）或 **(b) 发表阶段标签目录**（A-81 范式：`R1-submission` / `camera-ready` / `AEC-*`）。禁止混用 `CDO_8.1` / `LGMM 8.0` / `v2.0` / `RMT3.0` 等自由形态**新增**。
**机械判据**: 新建版本目录命中 §4.2 两形态之一的正则。
**通过门**: 新目录合规；存量目录进入 §4.3 的收敛清单（**本规范不要求一次性改名**，A-92 增量原则）。

### 4.3 单一真值 + 版本外置

**约定**: 同一制品（尤其 Lean 源码）**只允许一个真值源**；副本必须明确标注为"指向真值"或"已冻结归档"，并登记进 §5 血缘。
**依据**: I-1；H13（Lean 双源漂移，**裁决前不得删除任一份**）。
**通过门**: 双源存在时，`LINEAGE.md` 必须显式标注哪份为真值候选与依据（hash 对比结果）；未裁决时标 `undecided` 且**禁止删除**。

### 4.4 派生物隔离（编译产物与残留物）

**约定**: LaTeX 编译产物（`.aux` `.log` `.out` `.toc` `.dvi` `.bbl` `.blg` `.fls` `.fdb_latexmk` `.synctex.gz`）**不入库、不入源码区**；坚持用 `outDir` 重定向 + `autoClean`。
**依据**: A-78（**陈旧 `.bbl` 会产生错误参考文献**）。
**机械判据**:
```powershell
git ls-files | Select-String -Pattern '\.(aux|log|out|toc|bbl|blg|fls|fdb_latexmk|dvi|synctex\.gz)$'
Get-ChildItem $root\paper -File -Include *.aux,*.log,*.out,*.toc,*.bbl,*.blg,*.fls,*.dvi
```
**通过门**: 两段输出为空；`.gitignore` 含 LaTeX 产物段。

### 4.5 冻结与不可回退点

**约定**: 投稿/发布前须显式写下 **freeze 标记**与 **kill criteria**（推进/放弃的判据）；冻结后**只允许**改错与补合规，其余变更进 parking lot。
**依据**: A-57（scope freeze / scope lock 双层冻结）、A-59（kill criteria）、C-12（必须预先写定，防 renegotiation trap）。

## 5. 轴四 · 血缘

### 5.1 `LINEAGE.md`——最小血缘制品

**约定**: 每仓根一份 `LINEAGE.md`，**节点 = 制品版本**（版本目录 / 数据快照 / 论文稿 / Lean 源），**边**只允许三类且取固定字面量：

| 边 | 语义 |
|----|------|
| `derived_from` | 由某节点计算/写作而来（**数据/程序 → 产物**） |
| `supersedes` | 取代（**新版本覆盖旧版本**，旧节点保留） |
| `points_to` | 指向真值（副本 → 真值源；**不复制内容**） |

**机械判据**: `LINEAGE.md` 节点集与 `Get-ChildItem -Directory` 的版本目录集**双向差集 = 0**（未登记目录 / 幻影节点均为违规，同构于本仓 §9 索引双向对账）。

### 5.2 论文 ↔ 代码 ↔ 数据 的锚定

**约定**: 每仓在 `MANIFEST.md` 中登记**当前真值锚**：`paper` 稿路径 + `code` 入口 + `data` 快照标签 + **git tag/commit**。三者共用同一锚，避免"论文改了、代码没改"的静默漂移。

### 5.3 跨仓依赖登记

**约定**: 跨仓依赖（Lean 依赖库 / 共享数据 / 文献层）在 `LINEAGE.md` 以**引用键**登记，不复制内容（C-20 / B24）。
**Lean 专项**: 项目根须有 `lean-toolchain` + `lakefile.toml` + `lake-manifest.json`；`import` 只出现在模块 root；依赖钉 tag 不钉 main；**`.lake/` 不入库**。
**依据**: A-76。

### 5.4 blueprint（触发式，非首轮）

**约定**: Lean 制品的"依赖 + 证明状态"应由 **blueprint 自动导出**，人工文档只留 Explanation 层。
**依据**: A-77 / B21 / C-17（性价比最高但**懒加载**——触发条件 = 需要做成可被第三方独立核查的制品）。

## 6. 轴五 · 研究日志

### 6.1 `RESEARCH_LOG.md`：append-only + 固定字段

**约定**: 每仓根一份 `RESEARCH_LOG.md`（先例：`LGMM 8.0/RESEARCH_LOG.md`）。**append-only**；条目 = `## <ISO 日期>` 标题，正文固定四字段：

| 字段 | 内容 |
|------|------|
| **动作** | 本轮做了什么（可指到脚本/产物） |
| **读数** | 关键数字（**须是程序输出**，不是印象） |
| **决策** | 采纳/否决 + 理由（指向 `docs/decisions/` 若有） |
| **未决** | 本轮未闭合项（显式，禁静默跳过） |

**机械判据**: 所有 `^## ` 标题均命中 ISO 日期正则（比例 = 100%）；四字段在每条中出现（缺失者列清单）。

### 6.2 日志与 git 互锚

**约定**: 日志是**叙事**，git 是**证据**，两者以 commit 互相锚定——日志条目须能指到 commit（或声明"未提交"）。
**依据**: B2（状态提醒 = 宏写者序列的推进提示）；本仓 DEV-LOG 教训（事后补写必须如实标注）。

### 6.3 禁事后补写而不标注

**约定**: 事后回补的日志条目**必须**标注"事后叙事"，且不得伪造当时读数。
**通过门**: 回补条目带标注；**无标注的回补视为违规**。

## 7. 轴六 · spec 学术规范（论文仓内的纪律移植）

> **原则**: 移植**纪律**而非**工具**（本仓零依赖不变式 D6 同源）。论文仓不引入本仓的脚本，只引入"把话说实"的规矩。

| # | 约定 | 依据 |
|---|------|------|
| 7.1 | 重大变更（改方向 / 改数据口径 / 改核心定义）进 `docs/decisions/`，一件一档、命名唯一，写**采纳与否决两条路径** | 本仓 DECISION_RECORD_CONTRACT 同构 |
| 7.2 | 断言分级：**事实类**须给可核验来源、**推断类**须给编号推理链、**判断类**须给理由；**推测级不入结论** | [ASSERTION_EVIDENCE_FRAMEWORK.md](../../docs/ASSERTION_EVIDENCE_FRAMEWORK.md) |
| 7.3 | **声明 = 机械重数**：任何计数声明须能当场重算（轴一 §2.3 的推广） | 不变量 III |
| 7.4 | 独立审查须**异基座**（换模型/换人再跑一遍判据），不得自评自证 | 本仓 RULE-5 同构 |
| 7.5 | **懒加载 gate**：规范/工具只在触发条件成立时落地，不预先建成 | ADR-0010 |
| 7.6 | 同名必须同义：同名文件多处出现（`CODE_WIKI.md` ×9 / `document.tex` ×6–7 / `files.zip` ×10）须收敛或标注差异 | I-7；B24 |
